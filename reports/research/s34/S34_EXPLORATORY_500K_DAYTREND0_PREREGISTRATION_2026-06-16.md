- multiple-combination discovery accounting: 783 route/filter candidates evaluated;
- train/test out-of-sample split;
- historical real-fill parity using `book_ticker` bid/ask where available.

## 2. Frozen Rule Definition

- Symbol: `ETHUSDT`
- Liquidation side: `BUY`
- Direction: `LONG`
- Cluster threshold: `>= 500,000 USDT`
- Cluster bucket: `300 seconds`
- Minimum signal gap: `900 seconds`
- Entry delay: `0 seconds`
- Gate: no-lookahead UTC day-so-far trend `>= 0 bps`
- TP: `60 bps`
- SL: `40 bps`
- BE arm: `30 bps`
- Entry fill: taker ask
- SL/BE/time exit fill: taker bid
- TP fill mode: current runner config
- Max open trades: rule-scoped, `1`
- Daily max SL: rule-scoped, inherited current runner setting

The existing global S34 regime filter is not part of this rule. This rule uses only its own no-lookahead day-trend gate.

## 3. Forward Sample Criteria

Target exploratory sample: `N = 30` valid closed trades.

A valid trade must:

- be generated by `ETH_BUY_LIQ_LONG_500K_DAYTREND0_TP60_SL40_BE30`;
- pass the rule-specific day-trend gate at signal time;
- use real `book_ticker` executable fills;
- reconcile `net = gross - entry_adverse - exit_adverse - spread - fee`;
- not be `NO_FILL_DATA`.

## 4. Acceptance Criteria

At `N = 30`, the rule remains a candidate only if all hold:

- median `net_bps` > 0;
- mean `net_bps` > 0;
- cumulative `net_bps` remains > 0 after removing the top 3 winners;
- trades are spread across at least 8 different UTC days;
- `NO_FILL_DATA` rate is below 25%, or if above 25%, is not visibly concentrated during the highest liquidation-intensity windows.

Failure does not invalidate the main 50K/TP120 validation. It only kills or demotes this exploratory rule.

## 5. Discipline

- Do not tune thresholds during collection.
- Do not merge this sample into the 50K/TP120 pre-registered validation.
- Do not interpret performance before meaningful N; use interim checks only for data integrity, fill quality, and no-fill/quarantine behavior.
- Any rule/config change restarts this exploratory sample from `N = 0`.
