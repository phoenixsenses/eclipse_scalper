# Research Event Watchboard Trend

## Purpose

`event_watchboard_trend` summarizes how the top research event context changes across watchboard snapshots.

It answers:

- is the dominant event lane rising or fading
- did the top lane switch
- is priority pressure accelerating or cooling down

## First Deliverable

Tool:

- `python -m tools.event_watchboard_trend`

It emits:

- `summary`
- `latest`
- `points`
- `run_summary`

## Expected Use

Short term:

- trend card next to the event watchboard
- operator context on whether pressure is building or fading

Not yet:

- direct execution mutation
